# Карьерные чеклисты

Источник — [«Карьерное сопровождение»](https://docs.google.com/spreadsheets/d/1j5cJuUUNig5FsMlUd32S_A8W1vz7l8FO4gphHc9gyu4/edit), прочитан 19 октября 2026 года. Листы: «Чек-лист, индустрия» (1186594174), «Чек-лист, наука» (868093228), «Чек-лист, предпринимательство» (1006199104).

Данные находятся в `components/career-checklists.js`. Обзор целей и отдельная страница получают задачи через `getCareerStages(goal)`. Пустые после фильтрации этапы не отображаются. Идентификаторы индустриальных задач сохраняют прежние значения до фильтрации, поэтому исключение Mock-interview не сдвигает сохраненные отметки следующих задач. У науки и бизнеса собственные идентификаторы: старые отметки ошибочно показанных индустриальных задач не переносятся в новые чеклисты.

## Обработка источника

- Наука: 4 этапа, 13 задач. Пункты с пустой колонкой «Цель» отнесены к единственной научной цели на основании листа и колонки «Блок».
- Бизнес: 4 этапа, 12 задач. Пункты с пустой колонкой «Цель» отнесены к единственной предпринимательской цели. Повтор заявки в ускоритель (строки 12–13) объединен. Майнор относится к третьей ступени по колонке «Блок», хотя расположен перед ее заголовком.
- Комментарии, обсуждение межтрековых целей и служебные вопросы не становятся задачами.
- Ссылки взяты из источника; адреса с пометкой TBD не выдумываются. При отсутствии адреса задача остается доступной для отметки. Существующие кнопки с незаполненными адресами сохраняют состояние «Готовим».
- В источнике отмечена проблема доступа к научному хендбуку. Сохранен предоставленный адрес; актуальный доступ требует проверки владельцем документа.
- Для профилей специалистов источник содержит два адреса — для бакалавриата и магистратуры. Существующее действие «Открыть профиль» остается в состоянии «Готовим», пока нет выбора нужного профиля по уровню обучения.

## Завершение цели

После всех этапов каждого чеклиста отдельно отображается пользовательский пункт «Цель завершена» со стабильным идентификатором `goal-complete`. Он дополняет задачи из источника и не меняет их идентификаторы. Отметка сохраняется отдельно для каждого трека, меняет иконку цели на зеленую галочку и запускает конфетти; остальные пункты остаются доступны. При включенном уменьшении движения конфетти не запускается.
